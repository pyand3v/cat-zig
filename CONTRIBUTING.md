# Contributing to cat-zig

Thank you for your interest in this project! 

## No External Contributions

Please note that this project is **not accepting external contributions, pull requests, or feature requests** at this time. 

This repository is maintained solely for personal use, specific educational purposes, or as a static portfolio. To prevent confusion and save your valuable time, any open pull requests will be automatically closed.

## What You Can Do Instead

If you would like to modify the code, add features, or use it for your own purposes, you are welcome to **fork this repository** and make changes in your own copy. 

Thank you for understanding!
