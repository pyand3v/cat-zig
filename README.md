# cat-zig

This project is a reimplementation of the Unix command `cat`, inspired from the original implementation in GNU Core Utilities.
It is an education project aimed to understand the Zig language better.

## About cat-zig
`cat-zig` is a small educational reimplementation of Unix cat, built to explore Zig. It intentionally does not aim for feature parity or production use.

## Requirements
- Zig 0.16
