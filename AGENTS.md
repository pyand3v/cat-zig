## Commit Message Guidelines
 
### Format
- Use conventional commits: `type(scope): description`
- Types: feat, fix, docs, style, refactor, test, chore
- Keep first line under 50 characters
- Use imperative mood: "add" not "added"
 
### Examples
- feat(cli): stream file contents to stdout
- fix(cli): handle missing file arguments
- feat(cli): support multiple input files
- fix(io): report unreadable files
- test(cli): add file-copy test
- build(zig): add run and test steps
- chore(git): ignore Zig build artifacts
- docs(readme): add usage examples
